# DSTU Schedule Backend

Бэкенд сервис на **FastAPI** с SQLite и фоновым планировщиком **APScheduler** для мониторинга расписания ДГТУ (`edu.donstu.ru/api/Rasp`).

## Возможности
- **Offline-First кэш:** мгновенная отдача расписания из локальной базы данных. Если сервер ДГТУ недоступен, отдается сохраненная версия с пометкой `warning`.
- **Diff Engine:** выявление отмененных пар, смены аудиторий, замен преподавателей и новых пар.
- **Фоновый опрос:** автоматическая проверка изменений каждые 45 минут только для активных студентов.
- **API подписок:** прием FCM-токенов мобильных устройств для push-уведомлений.

## Запуск сервера

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера в режиме разработки
```bash
python -m uvicorn server:app --reload --port 8000
```
Сервер поднимется на `http://127.0.0.1:8000`.
Интерактивная Swagger-документация доступна по адресу: `http://127.0.0.1:8000/docs`.

## Эндпоинты API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка жизнеспособности сервиса |
| `GET` | `/api/schedule/{student_id}` | Получить расписание (кэш + живые данные + список изменений) |
| `GET` | `/api/changes/{student_id}` | История изменений (отмены, переносы) |
| `POST` | `/api/subscribe` | Регистрация устройства на пуш-уведомления |
| `POST` | `/api/sync-now` | Ручной триггер фоновой проверки всех студентов прямо сейчас |
